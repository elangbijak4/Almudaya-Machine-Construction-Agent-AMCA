## Issues found and corrected

1. The first fresh GUI interaction test reached the DAG view and exposed an unsupported `alt` parameter on `st.graphviz_chart` for Streamlit 1.66.1. Removed that parameter; the GUI integration test then passed.
2. The requirements omitted Streamlit's Graphviz Python dependency although the DAG UI uses `st.graphviz_chart`. Added `graphviz>=0.19.0` to `requirements-app.txt`, kept the dependency set narrower than the full `charts` extra, and reproduced installation in the clean environment.
3. Added automated coverage for the newly introduced agent CLI, GUI flow, and provider adapters. An initial run of the new tests exposed incorrect expected values in the test assertions; the assertions were corrected, and the complete suite subsequently passed.
